# End-to-end audit, October 2026

Scope: backend (API, data, detection, BigQuery layer, Gemini agent), frontend, deployment files. Method: code review, a live fuzz script against a running server, property-based tests of the detection engine, and hand-driven browser checks. "Fixed" means a test or a live check now covers it (named below). Anything not verified is under "Open".

## Strengths added

- Public data store: USGS earthquake catalogs downloaded as CSV with provenance (publisher, license, fingerprint, citation), stale detection, per-site seismic context that is clearly outside the risk score, a Gemini tool for it, and a template evidence line.
- BigQuery connection doctor: read-only checks with the exact fix for each failure; service-account key support; explicit warning that a Gemini key is not a Google Cloud credential.
- Operational: request ids, structured access log, readiness endpoint that reports backend and auth state, pinned dependency lock, Dockerfile.
