# Demo dataset provenance

**All motion values in this folder are SYNTHETIC (source = DEMO-SYNTHETIC).**
They follow the schema of pre-processed InSAR point products (Copernicus EGMS, COMET-LiCSAR) so real files can replace them. Coordinates are real geography used for context only. Rainfall in rain_demo.csv is also synthetic.

Generated with seed 42; last epoch 2026-10-10; 46 epochs at 12-day cadence (mimicking Sentinel-1).
